# **App Name**: Synergy Interns

## Core Features:

- Dashboard UI: Role-based dashboards for Intern, Mentor, and HR/Admin.
- Secure Access: Secure authentication with JWT, role-based routing, and protected API routes.
- Project Assignment: Mentor assigns projects/tasks to interns with titles, descriptions, deadlines and status tracking.
- Detailed Profiles: HR views detailed intern/mentor profiles with summaries of performance, projects, and feedback.
- Stipend Management: Stipend Management System to track disbursal month-wise, filter by status, and export reports.
- AI-Driven Insights: AI tool analyzes feedback and reports to suggest areas for intern development and improvement.
- Document Export: PDF generation of certificates, LORs, and stipend records for download.

## Style Guidelines:

- Primary color: A muted purple (#A084CF), evoking professionalism and creativity. This choice speaks to an organization with an open, artistic spirit, but also one focused on rules, structure and safety.
- Background color: A very light grey (#F0F0F3), for a clean and modern feel. This helps the purple stand out without being too stark, as the grey shares some of its hue.
- Accent color: A warm orange (#E4AECF) to highlight key interactive elements and CTAs. The contrast with purple ensures calls to action don't get lost, while the shared color family helps maintain harmony.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text.
- Use consistent and professional icons from a library like Phosphor Icons to represent different actions and entities. Icons should be line-based for clarity.
- Utilize a grid-based layout with Tailwind CSS, ensuring consistent spacing and alignment. Use shadcn/ui components for a polished look.
- Incorporate subtle transitions and animations (e.g., button hover effects, loading states) to enhance user experience. Keep animations short and purposeful.
